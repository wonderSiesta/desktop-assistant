# Desktop Assistant

桌面助手：日程、笔记、系统工具、截图收纳与互动桌宠。

## 运行

需要 Windows 10/11 和 Node.js 22.21+。首次运行需要网络以安装依赖。

```sh
npm ci
npm run build
```

随后双击 `启动.cmd`。程序通过原生快捷方式启动，命令窗口退出不影响助手。开发模式用 `npm run dev`，端口为 3220；免安装目录可用 `npm run pack` 在本机构建。

## 截图收纳

继续使用 Win+Shift+S，自动收集剪贴板的新图片并保存原始 PNG。支持预览、复制原图、多选导出、重命名、收藏、搜索与可恢复回收站。启动前与暂停期间的图片不自动补入；可手动导入当前图片。容量上限 2 GB，包含回收站，不会自动丢弃旧图。

新图片可能来自任何复制图片的程序，无法仅凭剪贴板可靠区分来源。快速覆盖掉的剪贴板内容无法恢复。文字历史默认关闭，可在截图页面开启；已有剪贴板记录保留。

## 桌宠

单击摸摸、双击开面板；悬停仅显示快捷按钮，不触发声音、特效或亲密度变化。拖动移动并记住位置。面板和右键菜单支持喂食、玩耍、睡觉、叫醒；睡觉不会暂停收图。

默认鲸鱼娘使用透明 WebM 角色动画，按动作播放，播完回待机。可切换狐狸、黄鸭、螃蟹和静态鲸鱼娘，也可上传 PNG/JPG/GIF/WebP，最大 10 MB。角色大小 64–240 px；可关闭自主动作、角色动画或点击音效。

关闭主窗口收回桌宠，真正退出使用右键或托盘「退出助手」。开机启动仅在打包版本开启。

## 数据与隐私

保持原项目的应用名称、应用标识及默认用户数据目录。原图、索引、宠物设置和上传形象都存于本机 Electron 用户数据目录，不提交 Git。可通过环境变量 `CAPTURE_DATA_DIR` 显式指定另一个目录。

截图不上传、不联网分析；没有新增全局键盘记录、OCR、API 账户或聊天依赖。Windows 辅助进程只查询剪贴板变更序号，图片未变化时不重复编码。拖动时暂缓读取图片，松手后恢复；隐藏窗口时暂停视频。
